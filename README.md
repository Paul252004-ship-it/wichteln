# 🎁 Wichteln

Einfaches Wichtel-Tool – eine einzige Seite (`index.html`), kein Server, keine Anmeldung.

1. Seite öffnen, Namen eintragen (einer pro Zeile), optional Budget/Datum/Ausschlüsse.
2. „Auslosen & Link erstellen“ – der Organisator sieht das Ergebnis **nicht**, es steckt verschleiert im Link.
3. Link in die WhatsApp-Gruppe schicken. Jeder tippt auf seinen eigenen Namen und sieht nur seinen Partner.

Extra sicher: Statt des Gruppen-Links kann jeder einen persönlichen Link privat bekommen.

Hosting: GitHub Pages (Settings → Pages → Branch auswählen → Save).
